# 🎙️ Speech Emotion Recognition System

**CodeAlpha Machine Learning Internship - Task 2**

A Machine Learning project designed to classify human emotional states (Neutral, Happy, Sad, Angry) from speech signals using audio feature extraction (MFCCs).

---

## 📌 Features
* **Audio Signal Processing**: Extracts Mel-Frequency Cepstral Coefficients (MFCCs).
* **Multi-class Classification**: Random Forest model predicting 4 core emotional states.
* **Interactive Web App**: Built with Streamlit for real-time speech feature testing.

---

## 🛠️ Project Files
* `app.py`: Streamlit application interface
* `emotion_model.pkl`: Trained Speech Classification Model
* `speech_emotions.csv`: Feature dataset
